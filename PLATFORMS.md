# Platform status

Updated 2026-09-25. VibePromptRig 5.1.6 is packaged as a Claude Code plugin. A public GitHub repository makes its source available to read or adapt; it does not install the plugin in other AI tools or put it in their directories.

| Platform | Verified status |
|---|---|
| Claude Code | Direct marketplace installation is the supported path. Automated setup writes are supported on Windows; macOS and Ubuntu receive a manual checklist. Authenticated first use of setup is pending. |
| Codex, Cursor, Antigravity, Grok, Grok Bot, Meta Muse, Instinct | No native VibePromptRig installation, parity, connector, or directory listing has been verified. |

A prompt can ask an assistant with file and network access to inspect this repository, but cannot by itself install a native plugin or grant permissions. Each additional host needs its own supported format, permission review, real installation test, and separately verified publication route. Platform names belong to their owners; no endorsement is claimed.
