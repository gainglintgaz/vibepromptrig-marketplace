# Privacy policy: VibePromptRig Lite

Effective 2026-11-19. Applies to the plugin vibepromptrig-lite, version 5.2.5 and later until replaced.

## What this plugin is

VibePromptRig Lite is a set of Markdown instruction files (skills and agents) that Claude reads. It contains no code, runs no hooks or scripts, and has no server, account, analytics or telemetry. The publisher operates no service that receives your data.

## What it collects

Nothing. The publisher does not receive your files, prompts, git history, names, email addresses or any other data, and nothing is stored by the publisher.

## What it can read

When you run a skill or agent, Claude may read files in the project folder you opened, and read-only git output such as commit subjects and author names, because the instructions ask it to. That reading happens inside your own Claude session, under your permission settings. Files are written only after you approve them.

## Where your data goes

Anything you and Claude process in a session is handled by Anthropic under Anthropic's own terms and privacy policy. A few agents (for example tech-radar) ask Claude to search the web with Claude's own tools; those requests follow your permission settings. This plugin adds no other network destination.

## Children

The plugin is a developer tool and is not intended for users under 18.
