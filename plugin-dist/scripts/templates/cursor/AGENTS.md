## Core discipline

1. **Architect-first** — Probe ambiguous scope before building. Non-trivial features need a written architecture artifact.
2. **Enforcement-first** — Load-bearing rules need mechanical gates, not prose alone.
3. **Secrets** — Never read `.env*` files. Use `.env.example` and code references.
4. **Data protection** — Agents work on dev by default. Destructive ops need explicit approval.
5. **Wired-not-orphaned** — Proven ≠ done. Done = applied everywhere, tested, reviewed, secured.
