# Code of Conduct

VibePromptRig is a tool for shipping production software. We treat each other the same way we treat the code: with rigor, honesty, and respect.

## Our standards

### Welcomed
- Specific, technical disagreement ("this rule misses case X" beats "this rule is bad")
- Empathy for newcomers — every senior dev was once confused by their first auto-loaded rule
- Productive critique — point at the artifact, not the person
- Sharing real-world examples (sanitized) — bugs you hit, fixes you tried, what worked
- Asking before assuming — context windows are short, your interpretation may be off

### Not welcomed
- Personal attacks
- Discriminatory language (race, gender, sexual orientation, religion, age, disability, etc.)
- Sealioning (asking questions in bad faith to wear someone down)
- Doxxing or sharing private info
- Spam, self-promotion outside dedicated channels
- Hate speech, threats, harassment

## Enforcement

If you observe a violation, contact maintainers via:
- Email: [maintainer-email]
- Direct message on Discord: @[handle]

We will respond within 48 business-day hours. We may:
1. Warn the user privately
2. Remove the offending content + warn publicly
3. Temporarily ban (1-7 days)
4. Permanently ban (for severe or repeat violations)

For paid customers (AI Webmaster + Enterprise tier), additional consequences may apply per contract.

## Scope

This code applies to all VibePromptRig spaces:
- GitHub repos
- Discord server
- Twitter/X interactions about VibePromptRig
- In-person events (if any)
- Email + DMs related to VibePromptRig
