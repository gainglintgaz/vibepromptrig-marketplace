# Delegation v1

Trigger: considering a child agent/model task.

Required: work solo by default. Delegate only when authorized and worthwhile. Give one responsibility, owned files, acceptance, permission limits, and evidence references. Use fresh-context dispatch where available. Target an authored brief <=1 KiB when feasible; retain required safety cards even when this exceeds the target and record why. Bound response to <=400 words plus evidence paths. No recursive delegation by default.

Prohibited: claiming the brief caps total context, bypasses host/system instructions, or guarantees savings; full-conversation forks when supported fresh context is suitable; spawning merely to appear thorough.

Verify: authored brief bytes; host-injected global/project/skill/tool context counted separately when observable, otherwise `unknown`; response bound and no child delegation.

Exception: safety content outranks the brief target.

References: `docs/rules-reference/context-v2-safeguards.md#delegation`.
