# Scope and Preservation v1

Trigger: every task.

Required: obey the current scope; inspect the repository, active branch/worktree, immediate caller, and reusable patterns; preserve unrelated edits; escalate when intent or risk expands.

Prohibited: silent scope expansion, blind rebases/merges, cleaning unrelated worktrees, forced whole-workspace cleanliness, and overwriting newer work with stale drafts.

Verify: report repository identity, branch/revision, in-scope changes, checks, unrelated dirt separately, and gaps.

Exception: none for destructive cleanup; obtain explicit authority for the exact target.

References: `docs/rules-reference/context-v2-safeguards.md#scope-and-preservation`.
