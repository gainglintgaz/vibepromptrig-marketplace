# Data and Finance Truth v1

Trigger: displayed metrics, money, projections, aggregates, exports, or financial/tax behavior.

Required: use real sources and reproducible derivations; preserve time-period attribution; keep money in exact integer minor units where applicable; show provenance and data basis; gate incomplete/unverified outputs; isolate tenants/modes; apply domain compliance only when the project actually has that capability.

Prohibited: fabricated/default user values, precise claims from insufficient data, cross-tenant/mode leakage, irrelevant exports, or universalizing tax/finance examples.

Verify: source-to-display and source-to-consumer trace, sparse/incorrect-period cases, exact math, and applicable legal review status.

Exception: static constants must be labeled as such and traceable to their versioned source.

References: `docs/rules-reference/context-v2-safeguards.md#data-and-finance-truth`.
