# UI Quality v1

Trigger: user-visible UI, styling, forms, navigation, or media.

Required: follow the project design system and approved visual target when required; use semantic accessible controls; design empty/loading/error/locked states; keep every visible action functional; respect keyboard, contrast, labels, reduced motion, and responsive behavior.

Prohibited: fake metrics, dead controls, ad-hoc style tokens, inaccessible div-buttons, or claiming visual/browser QA without running it.

Verify: affected routes/components, keyboard and accessibility checks, representative viewport/state review, console/network evidence when a runnable UI changed.

Exception: docs/CLI-only work records browser/visual checks as justified N/A.

References: `docs/rules-reference/context-v2-safeguards.md#ui-quality`.
